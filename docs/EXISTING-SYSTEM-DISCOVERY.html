Existing system discovery checklist

Mudita Hospital — Map how the reception server PC connects to the other clinic PCs. Print, fill downstairs, bring notes back.

Rules while you work
  • Prefer read-only (look, copy values, photo). Do not change passwords, uninstall, or stop services unless staff approve and you can restart them.
  • Redact passwords in notes; keep host, port, SID/service, and usernames.
  • Write the exact app names from Start Menu / desktop icons.
Suggested order (shortest path): (1) IPs + PC names → (2) Method A SQL Developer → (3) Method C5 Resource Monitor on one client → (4) Method C2/C4 if still unclear → (5) Method B for confirmation → (6) Fill the summary.

Method A — SQL Developer (fastest if Oracle)

Usually on the server PC. Start Menu → SQL Developer.

  1. Open SQL Developer.
  2. Left side: Connections (or green +).
  3. For each saved connection: right-click → Properties (or edit). Fill below.
  4. If Hostname is localhost or 127.0.0.1 → DB lives on this PC. Clients use this PC’s LAN IPv4 instead.
  5. Optional: Test connection (do not save password changes). Works? Y/N ________
