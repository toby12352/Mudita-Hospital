Mudita Hospital — Staff cheat sheet

Print and laminate for the OPD, OT, and pharmacy desks. Also: Help → Print cheat sheet in the app (? key).

1. Sign in

  1. Open Mudita on the clinic PC.
  2. First launch: enter Server IP (port 8080), e.g. 192.168.1.10.
  3. Sign in. Each desk opens only its own portal:
    • OPD: opd
    • OT: ot
    • Pharmacy: pharmacy
    • Admin: admin — pick OPD, OT, Pharmacy, or Settings
  4. Idle ~15 minutes → auto lock. Switch language English / မြန်မာ in the top bar.
  5. History lists this desk's bills only.

2. OPD bill (cash)

  1. OPD → New bill.
  2. Patient name → doctor → add a service or consultation. Medicines are billed in Pharmacy.
  3. Pay cash → Print (preview opens in the app).
  4. First receipt print: choose EPSON TM-T82 Receipt, paper 80 mm, no scaling / fit to printable width.
  5. Void needs a reason.

3. OT cupboard and bill

  1. Pharmacy: item → View → Send to OT (batch and qty). Pharmacy on-hand drops and the cupboard rises in that step.
  2. OT: OT cupboard shows on-hand. Return to pharmacy sends unused qty back.
  3. New OT bill from cupboard on-hand → Pay cash → Print. Pay deducts qty. Void puts it back.
  4. Print the pick list for a paper cart. There is no issue or reconcile step.

4. Pharmacy

  1. Pharmacy billing → new bill → medicines by code → Pay cash → Print. Void restores stock.
  2. Pharmacy stock → search by code or name. New item needs a code, prices, and a first batch.
  3. Restock an existing code (unknown codes must be created first).
  4. Low stock and near expiry are MAIN. Send a MAIN batch to the OT cupboard from the item view.

5. Reports

ReportWhoWhat
Daily cashThat deskPaid bills for that portal only
Combined daily cashAdmin dashboardPaid OPD + OT + pharmacy for a date
Low stockPharmacy / AdminMAIN qty ≤ reorder level
Near expiryPharmacy / AdminMAIN batches expiring within N days

The admin dashboard is the day book for the whole hospital.

6. Daily ops

  • Morning: confirm green Server connected.
  • Admin → Settings → Backup (also copy backup folder to USB weekly — see DEPLOY.md).
  • If Server offline / restore needed: crash / restore card at the server desk.
  • Training dry-run: Settings → Training → Seed (uses DEMO- codes and [TRAINING] patients only).
  • Press ? for in-app help.

Myanmar summary / မြန်မာ အကျဉ်း

  1. ဝင်ရန် — ဆာဗာ IP → အကောင့်ဝင် → ဘာသာစကား EN/မြန်မာ။
  2. OPD — လူနာ + ဆရာဝန် → ဝန်ဆောင်မှု → ငွေသားပေး → ပရင့်။ ဆေးသည် ဆေးဆိုင်တွင်။
  3. OT — ဆေးဆိုင်က ဆေးဗီရိုသို့ ပို့ → ဘေလ်ဆွဲ → ငွေသားပေး → မသုံးတာ ပြန်ပို့။
  4. ဆေးဆိုင် — ကုဒ်ရှာ → restock / item အသစ် → MAIN အသုတ်ကို OT သို့ ပို့။
  5. အစီရင်ခံစာ — မိမိဘေလ်သာ။ ဆေးရုံတစ်ခုလုံး ငွေစုသည် Admin ဒက်ရှ်ဘုတ်။
