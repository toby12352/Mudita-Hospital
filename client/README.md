# Mudita Hospital — Client

Tauri 2 + React + TypeScript desktop shell.

```powershell
npm install
npm run tauri:dev
```

Requires the API on `http://127.0.0.1:8080` (see root README). On Windows, run from a VS Developer environment (or use `scripts/run-client.ps1`) so MSVC/`cl.exe` is on PATH for the first Rust build.
